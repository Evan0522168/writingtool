# 學測作文線上打字稿紙 (Online Essay Typewriter Grid)

一個專為學測作文練習設計的網頁版線上直書打字稿紙。支援直接點選格子打字、自動換行縮排規範，並提供圖片/PDF 匯出與全文複製功能。

## ✨ 主要功能與特色

* **直接點擊打字**：點擊稿紙任意格子即可直接輸入（完美支援中文注音與拼音輸入法），自動移至下一格。
* **標準縮排規範**：按下 `Enter` 鍵自動換行，第一行預設留空 4 格（供填寫題目），第二行起自動縮排留空 2 格。
* **句號正常接續**：輸入句號 `。` 會填入當前格子並順移至下一格，不會誤觸換行。
* **鍵盤導覽與刪除**：支援 `Backspace` 退格刪除，以及方向鍵 `↑` `↓` `←` `→` 靈活移動游標。
* **一鍵輸出**：
  * 📋 **複製全文**：保留段落與格式一鍵複製至剪貼簿。
  * 🖼️ **下載 JPG** / 📄 **下載 PDF**：完整匯出全頁 38 行直書稿紙。
  * 🗑️ **清空重置**：一鍵清空稿紙內容。
